# Quoti Extension 0.1.3

This release refines portrait video card framing for early extension testers.

## Included

- Medium-portrait videos can use a taller media frame, reducing unnecessary cropping and aligning the browser preview more closely with Android output.

## Known Limits

- The extension remains distributed as a ZIP of `dist/` for developer/unpacked installation workflows.
- Capture behavior can be affected by source platform page changes.
- Browser video framing is a preview treatment; final exported video generation remains an Android capability.
