# Quoti Extension 0.1.0

This is the first early community package for the Quoti browser extension.

## Included

- Chrome Manifest V3 extension for X/Twitter post capture.
- Capture from the extension popup, right-click context menu, and optional inline Quoti button.
- Editorial Craft card rendering with light/dark theme and text/media modes.
- JPG download, image copy, source text copy, and source URL opening.
- Image and video media extraction from supported X/Twitter posts.
- Local video export through the bundled FFmpeg WASM renderer, with optional native renderer support when configured.

## Known Limits

- X/Twitter is the only supported social source in this early package.
- The extension is distributed as a ZIP of `dist/` for developer/unpacked installation workflows.
- Video capture depends on the media URLs exposed by the current X/Twitter page and may need real-post QA before public claims.
