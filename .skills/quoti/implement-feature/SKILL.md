# Implement Feature

Use this skill when adding a new Quoti feature.

## Steps

- Read AGENT.md.
- Confirm the feature supports the product vision.
- Keep the MVP scope small.
- Choose the owning area before writing code.
- Use React, TypeScript, CSS, and BEM.
- Use theme tokens for visual values.
- Add only the components and utilities needed now.
- Update documentation when the feature changes product, architecture, or design decisions.

## Done When

- The smallest useful version works.
- The implementation follows existing architecture.
- Documentation remains aligned with behavior.
