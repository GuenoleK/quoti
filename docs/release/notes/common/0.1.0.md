# Quoti 0.1.0

This is the first early community release package for Quoti.

Quoti helps people react across platforms while preserving the original conversation context. This package gives early testers both current surfaces from the same public version:

- the native Android companion app for the mobile share workflow;
- the browser extension for Chrome/Chromium developer install workflows.

## Install Expectations

- Android testers can install the APK directly on compatible Android devices.
- Extension testers can load the ZIP contents as an unpacked extension in a Chromium browser.
- Both packages are early testing builds and should be treated as community preview artifacts, not store-distributed production releases.
