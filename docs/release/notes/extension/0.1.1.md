# Quoti Extension 0.1.1

This release improves the browser extension and expands the early capture surface.

## Included

- Early capture coverage now includes Threads, LinkedIn, and Facebook in addition to X/Twitter.
- Platform detection, source metadata, and platform icons/badges have been updated for the broader source set.
- The popup now includes a gallery workflow for revisiting locally captured cards.
- The gallery design has been aligned with the mobile direction and local card management has been refined.
- Generated cards handle long links more cleanly and include layout polish for media, themed X badges, and exported card output.
- Local video export remains available through the bundled FFmpeg WASM renderer, with optional native renderer support when configured.

## Known Limits

- Non-X/Twitter capture is early and can be affected by platform page changes.
- The extension is distributed as a ZIP of `dist/` for developer/unpacked installation workflows.
- Video capture and export still depend on media URLs exposed by the current source page.
