# Quoti Android 0.1.0

This is the first early community package for the native Android companion app.

## Included

- Quoti appears as an Android share target for text and URL shares.
- X/Twitter post URLs are normalized into a Quoti card preview when enough public metadata is available.
- Shared URL-only posts show honest fallback states instead of inventing missing tweet content.
- Editorial Craft card previews support light/dark theme and text/media modes.
- PNG export, image copy, image sharing, and source URL copy are available.
- Video previews and MP4 card export are available for supported shared posts with playable media.

## Known Limits

- This package is a debug APK for early testing, not a Play Store or production-signed build.
- Public X/Twitter metadata availability can vary by post and sender app.
- The first MVP does not expose a post editor.
- Physical-device validation should still be repeated on the target community devices before treating the build as broadly stable.
