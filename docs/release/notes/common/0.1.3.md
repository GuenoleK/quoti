# Quoti 0.1.3

Quoti 0.1.3 is a patch release for early community testers across the Android companion app and the Chrome/Chromium browser extension.

## Highlights

- Portrait video cards now use a taller, centered frame more consistently between preview and exported output.
- Android imports from X and Threads are more careful about keeping the target post's text and media without pulling in unrelated page content.
- Android users can choose whether a quoted post is included in the card, and the action menu is more focused.
- Android video export handles a wider range of source audio formats by normalizing incompatible tracks when possible.

## Install Expectations

- Android testers can install the debug APK directly on compatible Android devices.
- Extension testers can unzip the extension package and load the extracted folder as an unpacked extension in a Chromium browser.
- Both packages remain community preview artifacts, not store-distributed production releases.

## Known Limits

- Android is still distributed as a debug APK.
- The extension package is still an unpacked/developer-install ZIP, not a Chrome Web Store package.
- Source text, media, and audio availability still depend on what each platform and sender app expose publicly.
