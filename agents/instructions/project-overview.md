# Project Overview

Quoti helps people react across social platforms while preserving the context of the original post.

It is not a social media manager, automation platform, or growth tool. It is a context and conversation tool.

## MVP Focus

- Browser extension.
- X support first.
- Post extraction.
- Card generation.
- PNG export.
- No backend.
- No database.
- No social API dependency.

## Video Rendering Direction

- Phase 1 should use bundled FFmpeg WASM inside the extension.
- Phase 2 may add an optional Native Messaging renderer for native FFmpeg performance.
- The extension should remain usable without a backend or native helper.

## Product Promise

Conversations should travel with their context.
