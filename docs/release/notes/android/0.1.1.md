# Quoti Android 0.1.1

This release improves the Android companion app for early mobile testing.

## Included

- Shared links from X/Twitter, Threads, LinkedIn, and Facebook are recognized and normalized when enough public metadata is available.
- X/Twitter tweet details and text selection handling have been improved for more reliable card context.
- The local library/gallery is faster to browse and easier to control, with refined search keyboard behavior, library selection controls, and a more polished translucent header.
- Multi-select in the gallery now supports long-press drag selection with edge auto-scroll for larger selections.
- Primary actions and library controls have been cleaned up for clearer copy, share, edit, and source workflows.

## Known Limits

- This package is a debug APK for early testing, not a Play Store or production-signed build.
- Public metadata availability varies by source platform, post privacy, and sender app.
- Non-X/Twitter share support is still early and should be validated with real shared posts.
- The first MVP still does not expose a full post editor.
