# Review Code

Use this skill when reviewing Quoti code.

## Steps

- Prioritize correctness, regressions, missing verification, and maintainability risks.
- Check alignment with product, architecture, and design instructions.
- Verify BEM naming and theme-token usage for frontend changes.
- Check that shared components are truly reused.
- Look for platform-specific logic leaking into shared layers.
- Keep feedback specific and actionable.

## Done When

- Findings are ordered by severity.
- Each finding names the affected file or behavior.
- Non-issues are not inflated into feedback.
