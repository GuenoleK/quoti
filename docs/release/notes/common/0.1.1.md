# Quoti 0.1.1

Quoti 0.1.1 is a patch release for early community testers across both current surfaces:

- the native Android companion app for mobile share workflows;
- the Chrome/Chromium browser extension for developer install workflows.

## Highlights

- Broader social-source groundwork is now included across the app and extension, with early support for Threads, LinkedIn, and Facebook in addition to X/Twitter.
- The gallery/library workflow has been added and refined so captured or shared cards are easier to revisit, search, select, and manage.
- Generated cards and previews received layout polish for media, long links, themed platform badges, and library displays.

## Install Expectations

- Android testers can install the debug APK directly on compatible Android devices.
- Extension testers can unzip the extension package and load the extracted folder as an unpacked extension in a Chromium browser.
- Both packages remain community preview artifacts, not store-distributed production releases.

## Known Limits

- X/Twitter remains the best-tested source path; newer platform coverage depends on the content or share metadata each service exposes.
- Android is still distributed as a debug APK.
- The extension package is still an unpacked/developer-install ZIP, not a Chrome Web Store package.
