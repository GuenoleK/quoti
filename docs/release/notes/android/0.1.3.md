# Quoti Android 0.1.3

This release improves portrait video presentation, source-post fidelity, and export controls for early mobile testing.

## Included

- Tall and medium-portrait videos now use a larger centered frame in both the card preview and final image or video export.
- Video frames use a consistent cover crop with rounded corners instead of introducing empty space around the source.
- Quoted posts can be included or hidden with a new `Main only` / `With quote` control, and that choice is respected by copy, share, and export actions.
- The action menu keeps the primary card actions and direct source opening while removing the redundant source-link copy action.
- X imports now prefer media explicitly associated with the target post over page-wide recommendation media.
- X text selection can recover fuller post text from public page metadata or visible share text while preserving natural trailing ellipses.
- Threads video URLs with escaped query characters are decoded correctly, and fallback extraction avoids unrelated surrounding-page images.
- Video export keeps compatible AAC audio directly and attempts to normalize other source audio to AAC-LC before muxing.

## Known Limits

- This package remains a debug APK for early testing until production signing is introduced.
- Platform metadata availability can vary by source service, post privacy, and sender app.
- If a source audio track cannot be decoded or normalized, the video can still export without audio.
