# Quoti Extension 0.1.2

This release improves browser capture consistency for early extension testers.

## Included

- X/Twitter link preview media is captured more reliably when posts include embedded preview cards.
- LinkedIn author identifiers now match the Android behavior by using profile-style handles such as `in/username`, `company/name`, or `school/name`.
- LinkedIn post URLs such as `/posts/username_...` can now provide an `in/username` fallback when the author profile link is not available in the page.

## Known Limits

- The extension remains distributed as a ZIP of `dist/` for developer/unpacked installation workflows.
- Capture behavior can be affected by source platform page changes.
- LinkedIn profile headlines are not pulled from protected profile pages; cards use stable public identifiers instead.
