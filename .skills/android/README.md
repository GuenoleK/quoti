# Android Skills

This folder vendors a small, curated subset of Google's official Android agent skills from:

```text
https://github.com/android/skills
```

Imported source revision:

```text
fe95b6fdf002ece6c7340013623d41d8deec6f52
```

Selected skills:

- `android-cli`: Android CLI, emulator, screenshots, layout inspection, SDK management, docs lookup.
- `edge-to-edge`: Compose edge-to-edge, system bars, navigation bars, IME, and insets.
- `testing-setup`: Android unit, UI, screenshot, and end-to-end testing strategy.
- `styles`: Jetpack Compose Styles API. This skill is experimental and requires alpha Compose APIs.
