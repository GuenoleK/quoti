# Generate Context Card

Use this skill when creating or changing Quoti card generation.

## Steps

- Start from normalized post data.
- Design for readability before decoration.
- Preserve the source context clearly.
- Use Editorial Craft principles.
- Support export-oriented layouts such as square, portrait, and landscape when needed.
- Keep rendering concerns inside card-generator.
- Avoid raw screenshots as the primary output.

## Done When

- The card is clean, legible, and shareable.
- The output can be exported as an image.
- Visual values come from the theme system.
