# Create Theme Token

Use this skill when a visual value needs to become reusable.

## Steps

- Check the existing theme tokens first.
- Add a new token only when the value represents a reusable design decision.
- Name tokens by role, not by a one-off component.
- Keep colors, typography, spacing, radius, shadows, and motion in the theme system.
- Replace hardcoded component values with tokens when appropriate.
- Update related documentation if the token changes the design language.

## Done When

- The token expresses a real design decision.
- Components consume the token instead of duplicating raw values.
