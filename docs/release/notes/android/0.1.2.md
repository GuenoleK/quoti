# Quoti Android 0.1.2

This release improves Android share handling and generated card output for early mobile testing.

## Included

- Shared X/Twitter links with preview cards can now retain richer linked media in the captured Quoti card.
- LinkedIn shared posts now prefer stable `in/username` author identifiers derived from public profile or post URLs when profile headline metadata is unavailable.
- LinkedIn author name, avatar, and profile URL metadata are extracted from public post pages when LinkedIn exposes them.
- Final exported cards now render platform icons consistently with preview cards, including LinkedIn, Threads, and Facebook.

## Known Limits

- This package remains a debug APK for early testing until production signing is introduced.
- Platform metadata availability can vary by source service, post privacy, and sender app.
- LinkedIn public pages do not reliably expose profile headlines, so LinkedIn cards intentionally use `in/username` instead of trying to fetch protected profile data.
