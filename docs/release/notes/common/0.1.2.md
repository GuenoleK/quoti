# Quoti 0.1.2

Quoti 0.1.2 is a patch release for early community testers across both current surfaces:

- the native Android companion app for mobile share workflows;
- the Chrome/Chromium browser extension for developer install workflows.

## Highlights

- Link preview media is now captured more reliably from X/Twitter cards across Android and the extension.
- LinkedIn cards now use stable profile-style identifiers such as `in/username` when public metadata does not expose a profile headline.
- Platform branding in generated cards is more consistent across the preview and final exported output.

## Install Expectations

- Android testers can install the debug APK directly on compatible Android devices.
- Extension testers can unzip the extension package and load the extracted folder as an unpacked extension in a Chromium browser.
- Both packages remain community preview artifacts, not store-distributed production releases.

## Known Limits

- Android is still distributed as a debug APK.
- The extension package is still an unpacked/developer-install ZIP, not a Chrome Web Store package.
- Source metadata availability still depends on each platform, post privacy, and the page or share surface that exposes the post.
